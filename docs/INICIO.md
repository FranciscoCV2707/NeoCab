## 🚀 LOS 4 PASOS (Después de leer)

1. **Crear repo GitHub** (5 min)
   ```
   github.com/new → nombre: neocab → crear
   ```

2. **Clonar localmente** (2 min)
   ```bash
   git clone https://github.com/TU-USUARIO/neocab.git
   cd neocab
   ```

3. **Inicializar Tauri** (10 min)
   ```bash
   cargo create-tauri-app --directory .
   npm install
   ```

4. **Verificar compilación** (5 min)
   ```bash
   npm tauri dev
   ```
