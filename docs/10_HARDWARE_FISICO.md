## 🪙 SISTEMA DE MONEDAS

### Opción A: Teclado como monedas

```
Mapeo:
5 = Insert coin
1 = Insert coin (alternativo)
P = Pausa
ESC = Menu

Ventaja: Simple, funciona
Desventaja: No es arcade real
```

**Código en ArcadeCore:**
```rust
match key {
    KeyCode::Digit5 => coin_mgr.insert_coin(),
    KeyCode::Digit1 => coin_mgr.insert_coin(),
    _ => {}
}
```

### Opción B: Botón coin (con USB encoder)

```
Conecta:
Botón físico → Pin 11 en I-PAC → USB → ArcadeCore
            → Detecta como tecla → coin_mgr.insert_coin()

Ventaja: Sentir de coin real
Desventaja: Fácil de presionar por error
```

### Opción C: Aceptador de monedas mecánico

```
Precio: $80-150 USD
Tipo: Bill/Coin Acceptor electrónico
Conexión: Serial RS-232
Protocolo: MDB (Multi-Drop Bus)

Ventaja: REALISIMO, historial monedas
Desventaja: Caro, requiere electrónica

Implementación en ArcadeCore:
- Serial listener en puerto COM
- Parser protocolo aceptador
- log de monedas en BD
```

**Código ejemplo:**
```rust
// src-tauri/src/hardware/coin_acceptor.rs
pub async fn listen_coin_acceptor(port: &str) -> Result<()> {
    let mut port = serialport::open(port)?;
    let mut buffer = [0u8; 4];
    
    loop {
        if port.read(&mut buffer)? > 0 {
            if buffer[0] == 0x02 { // MDB coin event
                coin_mgr.insert_coin().await;
                info!("Moneda detectada");
            }
        }
    }
}
```

### Opción D: Arduino + Sensor moneda DIY

### GPIO pinout para moneda/LED

```
Raspberry Pi 5 GPIO:

Pin 1   = 3.3V
Pin 2   = 5V
Pin 3   = GPIO2  (SDA I2C)
Pin 4   = 5V
Pin 5   = GPIO3  (SCL I2C)
Pin 6   = GND
Pin 7   = GPIO4
Pin 8   = GPIO14 (UART TX)
Pin 9   = GND
Pin 10  = GPIO15 (UART RX)
Pin 11  = GPIO17 ← COIN SENSOR
Pin 12  = GPIO18 (PWM 0)
Pin 13  = GPIO27
Pin 14  = GND
Pin 15  = GPIO22
Pin 16  = GPIO23
Pin 17  = 3.3V
Pin 18  = GPIO24
Pin 19  = GPIO10 (SPI MOSI)
Pin 20  = GND
Pin 21  = GPIO9  (SPI MISO)
Pin 22  = GPIO25
Pin 23  = GPIO11 (SPI CLK)
Pin 24  = GPIO8  (SPI CE0)
Pin 25  = GND
Pin 26  = GPIO7  (SPI CE1)
```

### Código Rust para GPIO moneda

```rust
// Cargo.toml
[dependencies]
rppal = "0.14"   # GPIO para RPi

// src-tauri/src/hardware/rpi_coin.rs
use rppal::gpio::Gpio;
use std::time::Duration;

pub async fn listen_coin_gpio() -> Result<()> {
    let gpio = Gpio::new()?;
    let mut pin17 = gpio.get(17)?.into_input();
    
    loop {
        if pin17.is_high() {
            info!("Moneda detectada en GPIO17");
            coin_mgr.insert_coin().await;
            tokio::time::sleep(Duration::from_millis(200)).await;
        }
    }
}
```
