## CÓMO LEER ESTA LISTA

```
Win7   = Funciona en Windows 7 SP1 x64
Win10  = Requiere Windows 10+

ARM    = Funciona en ARM / Raspberry Pi

Native = Adapter nativo en ArcadeCore
```

## CONFIGURAR EMULADORES EN YAML

```yaml
# config/emulators.yaml

emulators:
  # ── RETROARCH (multi-sistema) ──────────────────
  - name: retroarch
    display_name: "RetroArch"
    executable_win:   "C:/RetroArch-Win64/retroarch.exe"
    executable_linux: "/usr/bin/retroarch"
    executable_arm:   "/usr/bin/retroarch"       # Mismo en RPi
    args_template: "-L {core} --fullscreen {rom}"
    min_os_win: "7"

  # ── MAME ──────────────────────────────────────
  - name: mame
    display_name: "MAME"
    executable_win:   "C:/MAME/mame64.exe"
    executable_linux: "/usr/games/mame"
    executable_arm:   "/usr/games/mame"
    args_template: "{rom} -nowindow -skip_gameinfo"
    min_os_win: "7"

  # ── DUCKSTATION ───────────────────────────────
  - name: duckstation
    display_name: "DuckStation (PS1)"
    executable_win:   "C:/DuckStation/duckstation-qt-x64-ReleaseLTCG.exe"
    executable_linux: "/usr/bin/duckstation-qt"
    executable_arm:   "/usr/bin/duckstation-qt"
    args_template: "-batch -fullscreen {rom}"
    min_os_win: "7"
    requires_bios: true

  # ── PCSX2 ─────────────────────────────────────
  - name: pcsx2
    display_name: "PCSX2 (PS2)"
    executable_win:   "C:/PCSX2/pcsx2-qt.exe"
    executable_linux: "/usr/bin/pcsx2-qt"
    args_template: "-batch -fullscreen {rom}"
    min_os_win: "7"
    requires_bios: true

  # ── PPSSPP ────────────────────────────────────
  - name: ppsspp
    display_name: "PPSSPP (PSP)"
    executable_win:   "C:/PPSSPP/PPSSPPWindows64.exe"
    executable_linux: "/usr/bin/ppsspp"
    executable_arm:   "/usr/bin/ppsspp"
    args_template: "--fullscreen {rom}"
    min_os_win: "7"

  # ── DOLPHIN ───────────────────────────────────
  - name: dolphin
    display_name: "Dolphin (GC/Wii)"
    executable_win:   "C:/Dolphin/Dolphin.exe"
    executable_linux: "/usr/bin/dolphin-emu"
```
